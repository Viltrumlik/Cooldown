# Changelog

## 0.1.0 — 2026-10-30

First release.

- Menu bar app with live CPU speed limit / thermal state, memory pressure, swap, disk and top CPU processes.
- One-click clean for Xcode, simulators, Gradle, npm, Yarn, Bun, pip, Homebrew, CocoaPods, pub, editor caches, app caches and Trash.
- Stops booted simulators and Gradle/Kotlin daemons.
- Menu bar icon changes to a flame when the Mac is throttled by heat.
- `PathGuard` safety layer with unit tests.
- Universal (Apple Silicon + Intel) builds from GitHub Actions.
